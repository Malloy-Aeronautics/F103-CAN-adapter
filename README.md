# ArduPilot Project - Rangefiner Development

This repository is a fork of the ArduPilot project focused specifically on Rangefinder development, test and validation. The purpose of this fork is to provide an isolated environment for developing and debugging Rangefinder-related functionality without affecting the upstream ArduPilot project.

## Upstream ArduPilot ##

This project is based on the upstream ArduPilot repository:

ArduPilot

For general ArduPilot documentation, development information, and community support:

- ArduPilot Documentation
- Developer Documentation
- ArduPilot Discussion Forum
- ArduPilot Discord

## Hardware Platform ##

- MCU: STM32F303CCT6
- Hardware: Blackpill carrier board

## Scope ##

This is for U303-Universal DroneCAN RangeFinder, designed to interface with the LightWare LW20/C LiDAR RangeFinder.
