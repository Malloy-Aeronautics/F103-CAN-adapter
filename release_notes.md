# Release Notes for U303-Universal-CANSerial-RangeFinder 1.0.0 for RangeFinder (Lightware Lw20/C)

This document contains information related to firmware version 1.0.0 for the U303-Universal DroneCAN RangeFinder, designed to interface with the LightWare LW20/C LiDAR rangefinder. 

GUIDE:     Integrating.the.Lightware.Lw20.odt

Hareware:  Blackpill carrier board (STM32F303 CCT6)

Binary:    AP_Periph_with_bl.hex (follow GUIDE to build)
